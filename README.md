# Remarkable_templates
A collection of remarkable templates and the code and prompts used to make them.

The generated templates are for a Remarkable 2 and were generated with the uploaded prompt in Claude Desktop with Opus 5.5. I tested the Python script that generates the same.

### Weekly Journal
The weekly journaling template is indexed using the Swedish week numbering system with internal navigation links. The default version has pages that are 5 times as long as the Remarkable 2 screen, I prefer scrolling to having multiple pages per week.
